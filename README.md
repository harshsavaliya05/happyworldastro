## 💻 How to Run Locally

Since this is a static website, you can easily run it locally using any of the following methods:

### Method 1: Direct File Access
Simply double-click the `index.html` file in your file explorer to open it in your browser.

### Method 2: VS Code Live Server (Recommended)
1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Click the **Go Live** button at the bottom right of the editor.

### Method 3: Python HTTP Server
Run the following command in your terminal inside the project directory:
```bash
# For Python 3
python -m http-server 8000
```
Then visit `http://localhost:8000` in your web browser.
